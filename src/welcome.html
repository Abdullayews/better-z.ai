Z.ai Auto-Resend

system is busy və digər xətalarda mesajınızı attachment-larla birlikdə avtomatik yenidən göndərən extension.

Necə işləyir?

  1. chat.z.ai mesaj göndərəndə extension bu sorğunu yaxalayır (POST /api/v2/chat/completions — attachment-lar da daxil olmaqla).
  2. "Sistem məşğul" (global_limit), WAF bloku, 429, şəbəkə kəsintisi kimi yenidən cəhdlənəbilən xətalar avtomatik olaraq eksponensial gecikmə ilə (5s → 10s → 20s …) təkrarlanır.
  3. İmza (X-Signature) köhnələrsə — 4 dəqiqədən sonra — extension sorğunu yenidən imzalayır, ona görə retry-lər istənilən vaxt işləyir.
  4. Uğurlu retry-dan sonra tarixçə serverə yazılır (persist) və səhifə avtomatik yenilənir → mesajınız itmir, attachment-larınız itmir. ✓

Yoxlama (30 saniyə)

  1. chat.z.ai-ı açın.
  2. Brauzer konsolunda (F12) yazın: window.__zaiExtInject → true qayıtmalıdır.
  3. Bir mesaj göndərin; toolbar ikonkasına klik edin — "Şəbəkə jurnalı"nda completion → 200 (N əlavə) sətri görünməlidir.

Yeni: Preview nəzarəti (v1.1.0)

  • Fayl/şəkil preview-ləri artıq öz-özünə açılmır — cavab generasiyası bitəndə və ya fayl əlavə olunanda saytın açdığı preview-lər dərhal bağlanılır.
  • Preview yalnız siz fayla/şəkilə klik etdikdə açılır və açıq qalır.
  • Bu, standart olaraq aktivdir; istəsəniz ikonka → Ayarlar… bölməsindən söndürə bilərsiniz.

Yeni: Ağıllı köməkçi paketi (v1.2.0)

  • 📝 Qaralama mühafizəsi — yazdığınız mesaj avtomatik yadda saxlanılır; səhifə yenilənəndə "Bərpa et" təklifi görünür. Uzun promptlar artıq itmir.
  • 🧷 Mesaj xilası — göndərilməyən mesajın tam mətni pill-dəki ⧉ düyməsi və ya popup ilə bir kliklə kopyalanır.
  • ⚡ Snippet kitabxanası — tez-tez yazdığınız şablonları (Ayarlar → Snippetlər) kompozitor yanındaki ⚡ düyməsi ilə bir kliklə yerləşdirin.
  • ⤓ Söhbətin ixracı — popup-dakı "Söhbəti ixrac et" ilə bütün söhbəti Markdown (.md) faylı kimi yükləyin.
  • 🔔 "Cavab hazırdır" — tab arxa planda olanda uzun cavab bitəndə bildiriş gəlir.
  • 🚪 Popap bağlayıcı — "Currently in peak hours" kimi z.ai-in öz açdığı popaplar avtomatik bağlanılır (parol soruşan pəncərələr heç vaxt bağlanmır).
  • ⏸ Qlobal pauza — pill-dəki ⏸/▶ ilə bütün avtomatik retry-ləri dayandırın/davam etdirin.
  • 🎯 Ardıcıl retry — eyni anda yalnız bir mesaj yenidən göndərilir, sıra pozulmur.
  • 🛡️ Dublikat qorunması — retry-dan əvvəl server tarixçəsi yoxlanılır; mesaj onsuz da çatıbsa ikinci dəfə göndərilmir.
  • 📊 Statistika — neçə mesaj xilas olunub, neçə preview/popap bloklanıb (popup + Ayarlar).

Parametrlər

  • İkonkaya klik → Parametrlər, tam ayarlar üçün Ayarlar… düyməsi: maksimum cəhdlər (6), ilkin gecikmə (5s), imza yeniləmə, avto-yeniləmə, preview nəzarəti və s.
  • HUD (sağ altdakı kart) retry gedişatını canlı göstərir; "İndi cəhd et" — dərhal, "⏸" — pauza, "⧉" — mətni kopyala, "✕" — ləğv.

Yalnız chat.z.ai-də işləyir. Heç bir məlumat kənar serverə göndərilmir — tutulan sorğular yalnız brauzerin yaddaşında saxlanılır.
