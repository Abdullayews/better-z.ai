Preview control

Block file previews from opening automatically On (default): preview windows never open on their own — only when you click a file/image do they open. Previews the site itself opens when generation finishes or a file is added are closed instantly; the ones you opened by clicking stay untouched.

Draft guard

Save composer text automatically Your message is saved regularly; when the page reloads or the browser closes unexpectedly, a "Draft found — Restore" offer appears. Drafts are kept only in browser storage and never sent anywhere.

Popup closer

Auto-close popups like "Currently in peak hours" z.ai sometimes opens warning/ad windows on its own (peak hours, rate-limit warnings…). Windows matching the keywords are closed automatically. Windows asking for a password or containing a text input are never closed.

Word counter

Live word/character count next to the composer A small indicator appears in the bottom-right corner while typing: "12 words · 84 chars". Handy for sizing long prompts.

Full backup

Back up ALL chats (.md + .json) Popup → "Full backup" — downloads the chat list and the full history of every chat: human-readable Markdown + original structured JSON. Files are written only to your computer and sent nowhere.

Keyboard shortcuts

Enable shortcuts Works while a z.ai tab is open:
  • Alt+R — resend the pending message immediately ("Retry now")
  • Alt+P — pause/resume automatic retries
  • Alt+E — export the current chat as Markdown (.md)

You can also change the shortcuts in your browser's own manager — Chrome: chrome://extensions/shortcuts, Firefox: about:addons → Extensions → Manage Extension Shortcuts.
